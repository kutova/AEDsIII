ByteCodec

Biblioteca JavaScript para escrever e ler valores primitivos como vetores de bytes.

Configuração

Por padrão, a biblioteca usa big-endian: byte mais significativo primeiro. Todos os métodos write* retornam Int8Array. Por isso, bytes acima de 7F aparecem como valores negativos no vetor, embora a visualização hexadecimal mostre o valor binário esperado.
